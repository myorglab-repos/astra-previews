# Model B: Soft Arm Interface Spec v1 (for Ismael review)
Date: 2026-09-28 · Drafted by Ola · Replaces v0. Arm is Model A N1 unchanged; only the root mount changes.

## What changes from Model A
| Item | Model A | Model B |
|---|---|---|
| Arm | N1 soft arm | Same N1 arm, 100% scale, no changes |
| Root | Rotating carrier on the column | Fixed bracket inside the rear saddle, back ±56°, no yaw |
| Root standoff | Carrier ring | About 150 mm root center to 19 in bag surface |
| Air | Remote compressor | Pack on the saddle, short lines to each root manifold |
| Reaction path | Column and floor | Saddle, straps, bag, chain |

## Hard parts (all at the root, behind the foam boot, per Model A walkthrough rev N)
Arm flange 64 × 80 × 10 mm with four M8 screws; carrier tube 26 × 3 mm welded to the flange ending in a rounded eye for the harness; root manifold with metal valves and hard fittings. Nothing rigid past the shoulder.

## Interface requirements
- SI-B1 Root bracket takes the Model A J02 flange pattern (four holes on 40 × 52 mm) so the arm swaps unchanged.
- SI-B2 Eight flexible branches per arm (U1–U3, F1–F3, T1–T2), as Model A.
- SI-B3 Same pressure band and burst margin as Model A. Pack relief valve below arm burst ÷ 2.
- SI-B4 Arm mass: to be weighed. v0's 3 lb target is withdrawn because arms are full size.
- SI-B5 Contact force limit 100 N per arm (ASSUMPTION, drives E1 and E3).
- SI-B6 Vented arm returns to guard with no power.
- SI-B7 Bag clearance ≥ 14 mm across all Model A strikes (model result); keep ≥ 10 mm after cover bulge (ASSUMPTION).
- SI-B8 Arm foam and contact sleeve stay at Model A thickness (about 143 mm OD upper arm, 129 mm forearm, measured in the mesh) unless T-11 supports thinning.
