# G. Interface vulnerabilities — DFMEA inputs

DFMEA means design failure mode and effects analysis. No risk-priority numbers are invented.

| Objects / interface | Failure mode | Follow-up |
|---|---|---|
| ATLAS_L/R_PROTECTED_ROOT_PITCH, recessed carrier | Pitch travel, root bearing or anchor load-path failure. | B-06 actual hardware, stops and load testing. |
| M1_L/R_U/F__foam_and_contact_sleeve | Sag or tolerance erases narrow G-03 gap. | Loaded envelope and continuous collision tests. |
| Integral soft feeds, strain limiting and return textiles | Kink, pullout, fatigue, unequal elastic return. | RH-03/B-03 material and retention coupons. |
| M1_L/R__foam_textile_glove / wrist core | Prescribed surface entry differs from loaded aim. | Actual partial-stroke system identification; do not enable 50% head shots from this atlas. |
| Fixed covers / rotating shoulder band | Seams close nominal axial gap. | G-05 stackup and physical motion tests. |

**Track A does not prove strike impulse.** No measured pneumatic propulsion, force, durability, loaded reach or real CV result is supplied.
